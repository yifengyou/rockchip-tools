远端接入方式

当前控制台：

Linux / macOS 通过 TCP 桥连接（端口以 rkttl 主机端"TCP 桥"设置为准，默认 9999）：

# 1) nc 交互（最简单）
nc  9999

# 2) socat 终端模式（回显更接近真实终端）
socat -,raw,echo=0 TCP::9999

# 3) 伪装成本地串口设备（供只认 /dev/tty* 的工具使用）
socat pty,link=/tmp/ttyrkttl,raw TCP::9999
screen /tmp/ttyrkttl 1500000
  1. TCP 桥支持多客户端同时收发，与网页控制台共享同一路串口（tmux 式）。
  2. 连接后会先收到一行 rkttl 状态横幅，之后为纯透传。
  3. Windows 主机首次开桥时请允许防火墙放行该端口。
  4. 程序化访问建议用 HTTP API（curl）而非 TCP：见项目 README 的 /api/read、/api/write。
