rkttl 串口共享终端 未连接
● 未连接 RX 0B TX 0B 共享 0 直接在终端输入 · Ctrl+C 会直接发送给设备

远端接入方式

网页控制台：

TCP 桥（端口以宿主机设置为准，默认 9999）：

nc  9999
socat -,raw,echo=0 TCP::9999
socat pty,link=/tmp/ttyrkttl,raw TCP::9999
screen /tmp/ttyrkttl 1500000

HTTP API（脚本 / AI）：

curl -H "Authorization: Bearer $TOKEN" http://:7373/api/status
curl -H "Authorization: Bearer $TOKEN" http://:7373/api/write -d '{"data":"version","eol":"crlf"}'
curl -H "Authorization: Bearer $TOKEN" "http://:7373/api/read?since=0"
